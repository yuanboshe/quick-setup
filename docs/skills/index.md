# Agent Skills

当前发布两个 quick-setup Agent skill。skill 真源放在仓库一级目录 `skills/` 下，方便从 GitHub 项目首页直接发现；文档站构建时会从该目录生成 raw 下载文件。

仓库入口：

```text
https://github.com/yuanboshe/quick-setup
```

## qs-command

用途：约束 Agent 如何调用、解释和记录 QS 命令，覆盖 `render`、`run`、`explain`、`list templates`、`inspect template`、`last`、repo cache、`qs ghx`、远程输入和 JSON 输出等场景。

下载路径：

```text
https://qs.pz1.top/skills/qs-command/SKILL.md
```

仓库路径：

```text
skills/qs-command/SKILL.md
```

## qs-repo

下载路径：

```text
https://qs.pz1.top/skills/qs-repo/SKILL.md
```

仓库路径：

```text
skills/qs-repo/SKILL.md
```
